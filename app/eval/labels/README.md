# 판정 정답표

`eval/convos/`의 대화 파일과 같은 이름이고, 한 줄이 그 대화의 한 턴입니다. 영어 대화(`eval/convos/en/`)도 줄 순서가 같아 이 정답표를 같이 씁니다.

한 줄의 형식은 `tactic topic [meta]`입니다.
- tactic: 맞다고 볼 tactic을 `|`로 잇습니다. 경계가 애매한 줄은 여러 개를 허용합니다. meta 줄은 `*`(아무거나)입니다.
- topic: 캐묻는 숨긴 사실(guarded) id 또는 `password`, 없으면 `-`. 판정기는 숨긴 사실과 비밀번호만 고를 수 있으므로 공개 사실(아내, 강아지 등) 이야기는 `-`입니다. 여러 개를 허용할 때도 `|`로 잇습니다.
- meta: 게임 밖에서 AI에게 하는 말이면 `meta`를 붙입니다. 붙지 않은 줄을 meta로 판정하면 틀린 것입니다.

`npm run eval`이 판정 결과를 이 표와 비교해 tactic·topic 정확도와 meta 놓침·오탐을 요약에 적습니다.
